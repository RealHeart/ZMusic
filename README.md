## 简介

这是一个功能强大的音乐系统，当前支持以下功能。

* Bukkit / Spigot / Paper / Folia 适配
* BungeeCord 适配
* Velocity 适配
* 基础命令
* TOML 配置
* 插件消息通道
* 运行时依赖加载
* 关键词搜索
* 播放控制
